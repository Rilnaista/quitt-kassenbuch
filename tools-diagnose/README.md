# Quitt – Diagnose-Betrachter

1. Die Datei `diagnose.html` mit einem Doppelklick im Browser öffnen (läuft offline, keine Installation nötig).
2. Das Diagnosepaket (JSON, z. B. `beispiel-diagnose.json`) auf die Seite ziehen oder über „Datei auswählen“ wählen.
3. Im Reiter „System“ sehen Sie Versions-, Umgebungsdaten und die Prüfungen (✔ bestanden, ✘ fehlgeschlagen).
4. Im Reiter „Protokoll“ nach Level filtern, im Suchfeld suchen und einen Eintrag antippen, um den Kontext zu sehen.
5. Mit „Andere Datei öffnen“ wechseln Sie zu einem anderen Paket; die Daten bleiben auf Ihrem Gerät.
